# Website and operations release — 9 September 2026

The public site now has a redesigned responsive hero, linked service overview, clearer service navigation, consistent button contrast, and keyboard-accessible mobile navigation. Existing content and uploaded hero images remain managed through Homepage & About Content. New hero introduction fields support English and Bengali.

The admin Operations page brings pending domain payments, failed orders, upcoming renewals, overdue invoices, support tickets and lead follow-ups together. Each section respects the user's existing permissions. System administrators can also see queue counts and whether a production mail transport is configured.

Domain order improvements:

- Show failure details in the list and give the table more screen space.
- Store EPP codes supplied when an admin creates a transfer order.
- Enforce manage permission for payment confirmation, retry, cancellation and transfer checks.
- Show the registrar transfer status and last check time in the order details.
- Provide a rate-limited read-only registrar status check; it never submits another transfer.
- Explain multi-day transfer processing to customers and keep order status pages out of search indexing.

Verification includes the Laravel test suite, production asset build, desktop/tablet/mobile browser checks, keyboard navigation, an automated WCAG A/AA scan of public pages, and authenticated local admin rendering. Automated scans do not certify complete accessibility or replace user testing.

Deployment uses the committed package lock with `npm ci` and clears Filament component discovery caches so new admin pages appear. No schema migration or customer data replacement is needed for this release.

Payment gateways still require an approved merchant account and live credentials. Existing demonstration case studies/testimonials should be replaced with approved real client material before being used as evidence of delivery. No new client results, reviews or performance guarantees were invented for this release.
